# 🛍️ ShopNova

ShopNova is a modern e-commerce web application designed to provide users with a simple and intuitive online shopping experience.

## ✨ Features

- 🛒 Browse products
- 🔍 Search and explore products
- 📱 Responsive design
- 🎨 Modern and clean user interface
- ⚡ Fast and lightweight
- 🛍️ Shopping experience
- 🖥️ Flask backend
- 📄 Product pages

## 🛠️ Technologies

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Tools
- Git
- GitHub
- Visual Studio Code
